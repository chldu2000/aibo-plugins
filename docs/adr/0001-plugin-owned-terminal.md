# 外部插件拥有完整终端能力

工具面板终端由 `aibo-plugins` 中的外部插件负责渲染、shell 发现与启动、PTY 及交互管理，Aibo 宿主提供通用插件容器、授权、通信和生命周期监督。选择该边界以使终端引擎能够随插件独立演进，而不是由插件仅提供入口、全部终端实现随宿主发布。

当前受限 Presentation Worker 不足以承载完整终端前端，因此需要新增隔离自定义工具视图及按“工作区＋窗口”归属的长驻运行合同；不直接放开既有视觉树或任意宿主原生命令调用。代价是插件承担各平台原生依赖的打包和验证，宿主仍需协调关闭确认以及插件故障、停用和退出时的清理监督。

同一窗口内同一工作区的聊天共享终端，不同窗口的终端各自独立；视图故障不终止后台实例，后端故障则清理所属进程且不自动重启 shell。

产品行为及验收范围见 [设计确认稿](../terminal-plugin-design.md)。本架构决策及整体设计已确认，已按此分工实现。
